# Installation Guide

The latest version of the app can be run online at
[billipod.solidcommunity.au](https://billipod.solidcommunity.au) from
your browser with no installation required. Or else download and
install a package for your platform from the platform repository or
else directly from the [Solid Community AU](https://solidcommunity.au)
repository. The choice is yours:

<!-- markdownlint-disable MD036 MD013-->

+ **Web**
  [solidcommunity](https://billipod.solidcommunity.au/);
+ **Android**
  [apk](https://solidcommunity.au/installers/billipod.apk) or
  [aab](https://solidcommunity.au/installers/billipod.aab);
+ **iOS**
  Apple App Store - coming soon;
+ **Linux**
  [Snap Store](https://snapcraft.io/billipod) or
  [deb](https://solidcommunity.au/installers/billipod_amd64.deb) or
  [flatpak](https://solidcommunity.au/installers/billipod_amd64.flatpak) or
  [snap](https://solidcommunity.au/installers/billipod_amd64.snap) or
  [zip](https://solidcommunity.au/installers/billipod-linux.zip);
+ **macOS**
  [dmg](https://solidcommunity.au/installers/billipod-macos.dmg) or
  [zip](https://solidcommunity.au/installers/billipod-macos.zip);
+ **Windows**
  [exe](https://solidcommunity.au/installers/billipod-windows-inno.exe) or
  [zip](https://solidcommunity.au/installers/billipod-windows.zip).
